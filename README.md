# TeamForge 🚀

## Student Project & Team Building Platform

TeamForge is a web-based platform designed to help students find suitable teammates for college projects, hackathons, competitions, and other technical activities.

Students can create profiles, add their skills and interests, create projects, discover other students, and send or receive team joining requests.

---

## 🎯 Problem Statement

Students often have good project ideas but may not have a complete team with the required technical skills.

For example, a student may know Python and Machine Learning but need teammates with:

- React
- UI/UX Design
- Java
- Data Science

TeamForge helps students discover and connect with teammates based on their skills and interests.

---

## 💡 Solution

TeamForge provides a common platform where students can:

- Create their student profile
- Add their technical skills
- Add interests
- Create project ideas
- Search for projects
- Find students with required skills
- Send team joining requests
- Accept or reject requests
- Manage their project team

---

## ✨ Key Features

### 👤 Student Profile
Students can create profiles containing their skills, interests, and basic information.

### 📌 Project Creation
Students can create projects and specify the skills required for the project.

### 🔍 Project Search
Users can search and explore available projects.

### 🤝 Team Join Requests
Students can request to join projects and project owners can accept or reject requests.

### 👥 Team Management
Project owners can manage their team members.

### 🤖 AI Skill Matching
A future/extended feature can match students with projects based on the similarity between:

**Student Skills ↔ Project Required Skills**

This can help students discover projects that fit their skill set.
